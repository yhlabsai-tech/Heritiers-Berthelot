# Docs

Non-sensitive artefacts that support the logbook — the kind of thing that's
safe to show in public and helps a reader understand the project.

**What belongs here**

- Architecture diagrams (e.g. how the platform is structured).
- Anonymised governance charts.
- Public-facing notes and records of design decisions.

**What never goes here**

- The statutes or internal regulations (they contain personal data).
- Members' names, addresses, or contact details.
- Internal strategy or documents still under discussion.

Anything sensitive stays private — off GitHub entirely. That's a GDPR
requirement, not a preference.
